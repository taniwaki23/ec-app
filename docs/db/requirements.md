# 業務要件

- 作成日: 2026-10-07
- 前提: 小規模 EC(1日約50件の注文、店側のスタッフ2〜3人)。発注(仕入れ先への注文)は含めない(`docs/frontend/screens.md` の範囲の判断)

## 登場人物

| 登場人物 | 説明 |
|---|---|
| 顧客 | 会員登録して商品を買う人 |
| 一般スタッフ | 店の日常業務(注文の処理、出荷)をする人 |
| 管理者 | 一般スタッフの操作に加え、お金と在庫の数字を動かす操作をする人 |

- 倉庫担当は分けない。スタッフ2〜3人の規模では、同じ人が出荷まで行うため(DB プランの当初案は4種類だったが、2026-10-07 に2種類に決定)

### 店側の権限

判断の基準: **売上・お金・在庫の数字を直接動かす操作は管理者だけ**にする。

| 操作 | 一般スタッフ | 管理者 |
|---|---|---|
| 注文一覧・注文詳細を見る | ○ | ○ |
| 注文を「引当済み」「出荷済み」にする | ○ | ○ |
| 入金を確認済みにする | ○ | ○ |
| 商品の値段を変える | × | ○ |
| 商品を登録する・販売を止める | × | ○ |
| スタッフのアカウントを作る・権限を変える | × | ○ |
| 在庫の数を直す(入荷・棚卸しの差) | × | ○ |
| 店側から注文をキャンセルする(出荷前) | × | ○ |

- 在庫の数を直すのを管理者だけにした理由: 誰でも数を減らせると、持ち出しなどの不正を在庫の調整で隠せるため
- 店側からのキャンセルを管理者だけにした理由: 返金というお金の動きが伴うため
- **代償(未解決)**: 入荷のたびに管理者の操作が必要になる。管理者が不在の日は入荷が在庫に反映されず、在庫ゼロのまま売れない時間が出る。対策の候補(入荷による「増やす」操作だけは一般スタッフにも許すなど)は、業務要件③(入荷のルール)で決める
- 顧客が自分で行うキャンセル(出荷前、注文詳細の画面から)は別のルールとして業務要件②で決める

## 支払い方法

- **クレジットカードと代金引換の2つ**(2026-10-07 決定)。銀行振込(前払い)は扱わない
- 理由: 状態を少なくする。銀行振込を入れると「入金待ちの取り置き在庫をいつ戻すか」の状態と期限処理が増える
- 代引に特有の問題: 受取拒否(商品が店に戻る)。業務要件③で扱う

## 在庫引当のタイミング

- **注文確定と同時に、システムが自動で引き当てる**(2026-10-07 決定)。在庫が足りなければ、その場で「在庫切れ」として注文を受け付けない
- 理由: 業務の流れを最小限にする。スタッフの確認作業とお客さんへの連絡が要らず、お客さんも注文の時点で結果が分かる
- 捨てた案: 注文をいったん受け付け、スタッフが確認して引き当てる(在庫切れのときにスタッフの連絡の手間と、お客さんの待ち時間が出る)
- 代償: 最後の1個の取り合いが、システムの中で同時に起きる。売りすぎないように DB で正しく防ぐ必要がある → DB の ADR-002(在庫引当の方式)と、BE の注文確定 API(10/14〜)で扱う

## 業務の流れ

### クレジットカード

| 段階 | 誰が | 何をするか |
|---|---|---|
| 注文 | 顧客 | カートの内容で注文を確定し、カード情報で決済する |
| 在庫引当 | システム | 注文確定と同じ処理の中で在庫を減らす。足りなければ注文を受け付けない(決済もしない) |
| 出荷 | 一般スタッフ | 梱包して発送し、注文を「出荷済み」にする |
| 入金 | (決済会社) | 後日、決済会社からまとめて入金される。注文ごとの入金確認はしない |

### 代金引換

| 段階 | 誰が | 何をするか |
|---|---|---|
| 注文 | 顧客 | 支払い方法に代引を選んで注文を確定する |
| 在庫引当 | システム | クレカと同じ |
| 出荷 | 一般スタッフ | 梱包して発送し、注文を「出荷済み」にする |
| 入金 | 一般スタッフ | 配達時に顧客が配送会社へ支払い、配送会社から店に入金されたら、注文を「入金確認済み」にする |

### キャンセル(出荷前)

| 誰が | 何をするか |
|---|---|
| 顧客 | 注文詳細の画面から自分の注文をキャンセルする |
| 管理者 | 顧客からの連絡などを受けて、店側からキャンセルする |
| システム | 引き当てた在庫を戻す。クレカなら決済を取り消す(返金) |

- 出荷後のキャンセル、顧客がキャンセルできる条件、代引の受取拒否は、業務要件②③でルールとして決める
